# S1: kostur, `npm run check`, uvoz župa

Polazni commit: d4834b2. Koda nema. Odluke od **300**.

Paket:

1. **Kostur po `../omm.domovina.ai`** (čitaj njegov `package.json`, `wrangler.jsonc`,
   `astro.config.mjs`, `src/worker.ts`, `src/middleware.ts`; ne kopiraj OCR, HEP, mail,
   izvještaje ni admin). Astro 7 SSR + `@astrojs/cloudflare`, TypeScript, D1 binding `DB`
   (`migrations/`). `wrangler.jsonc`: ime `listici-domovina-ai`, `"workers_dev": true`,
   **bez `routes` i `custom_domain`** (to je S9), `account_id` isti kao omm (račun D.O.M.).
   D1 baza se ne stvara na udaljenom računu u S1: radi se `--local`. Ako zatreba
   `database_id`, upiši privremeni i zapiši odluku.
2. **`npm run check`** = `astro check` + `vitest run` (testovi bez mreže). Dodaj
   `npm run dev:worker` = `wrangler dev --local`, jer `npm run dev` ne hvata zamke Workera.
3. **Migracija `zupe`**, koja čuva sve što treba za vezu i prikaz:
   - **ključevi:** `slug` (ključ veze), `oib` (može biti prazan), `registry_id` / SBT_ID,
     `kind`, `diocese`;
   - **opis:** `name`, `short_name`, `titular`, `address`, `city`, `county`, `churches`
     (JSON ili zasebna tablica `crkve_izvor`, odluči i zapiši);
   - **koordinate:** `lat` i `lng` **samo ako `geocode_source` nije Google**;
   - **ne preuzimaju se:** `phone`, `website`, `google_maps_uri` (odluka 3, CLAUDE.md).
   - **stanje uvoza:** `uvezeno_u`, `nestalo_u` za slug koji nestane.
4. **Uvoz** `scripts/uvoz-zupa.ts` (ili ruta za cron, odluči): dohvati
   `https://crkve.domovina.ai/data/zupe-index.json`, filtriraj `kind == "zupa"`, za
   detalje `data/zupa/<slug>.json`.
   - **Idempotentan:** drugi uzastopni uvoz ne mijenja ništa.
   - **Bilježi** nove, promijenjene i nestale slugove. Ako slug nestane, a isti OIB ili
     SBT_ID dobije novi slug, to je preimenovanje, ne brisanje.
   - **Testovi** s malim fixtureom u `test/fixtures/` (ručno napisan, 5–10 župa, uključujući
     župu bez OIB-a i Google koordinate), bez mreže.
   - **Stvarni uvoz** u lokalnu D1 jednom: zapiši broj (2026-11-20 indeks je imao
     `count` 2358 i 1561 `kind == "zupa"`) i trajanje. Detalji 1561 župe su 1561 HTTP
     zahtjev prema crkve.domovina.ai, pa ih pusti sekvencijalno ili s malom paralelom.
5. **Stranica `/zupa/<slug>`**: naziv, biskupija, mjesto, crkve, bez kontakata. Za sada
   to je samo dokaz da uvoz i čitanje rade. Plus `/` s pretragom po nazivu/mjestu
   (može biti obična forma).
6. **Javi crkve lancu** (ne mijenjaj crkve repo, samo zapiši u njegov handoff ili kao
   bilješku korisniku): Vugrovec (Sesvete), Vinjani i Vidici (Šibenik) nisu u
   `zupe-index.json`; slug Starog Pazina i Duge Rese u R1 je pretpostavka. Provjeri prvo
   jesu li u međuvremenu dodani.
