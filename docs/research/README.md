# Istraživanja

Svako istraživanje ide u `YYYY-MM-DD-<tema>.md`: pitanje, metoda, izvori (URL + datum
dohvata), brojke s načinom kako su dobivene, zaključak i odluke koje iz njega slijede.

Prikupljeni uzorci (PDF, slike, tekst tuđih listića) žive u `data/uzorci/`, koji je
gitignoran. U git ide samo izvedena analiza, bez osobnih podataka iz listića.
